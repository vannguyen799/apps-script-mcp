Thêm Apps Script

Phiên này hết hạn sau 30:00.

Cách 1: Script mới (dán một file, không cần nhập mã)

  1. Tải hoặc copy file Code.gs đã được cá nhân hóa cho bạn:
    Tải Code.gs
  2. Mở script.new, xóa nội dung mặc định của Code.gs, dán vào và lưu.
  3. Deploy → New deployment → Web app, chọn Execute as: Me và Who has access: Anyone, rồi cấp quyền bằng tài khoản Google của bạn.
  4. Copy URL web app (dạng https://script.google.com/macros/s/.../exec) và dán vào đây:

Personal Access Tokens (PAT)

Dùng cho Claude Code / Claude Desktop qua header. Mỗi PAT gắn với một kết nối Apps Script.

script.eval cho phép token này chạy mã Apps Script tùy ý bằng tài khoản Google của bạn (bỏ qua danh sách bảng tính được phép; rủi ro prompt injection). Chỉ tick khi thật sự cần, và phải bật thêm trong trang quản trị Apps Script.

Sao chép token ngay - sẽ không hiển thị lại.
